# AZRI Landing Page

AZRIの業務システム開発・要件定義・保守運用の考え方を伝える、静的なコーポレートLPです。

「焦らず決めて、速くつくる。」を中心メッセージに、機能の多さではなく、業務理解・デモによる認識合わせ・変更管理まで含めた開発の進め方を表現しています。

## このサイトで伝えること

- 作り始める前に、現場の業務と例外を整理する
- 文章だけで決めず、操作できる画面で認識をそろえる
- 対象範囲、対象外、見積前提を明確にして手戻りを減らす
- 追加要望は費用・納期・影響範囲を確認してから着手する
- 納品後のバックアップ・監視・改善まで見据える

## 実務デモ

### 案件進行管理

架空の「受発注管理システム刷新案件」を題材に、次の情報を切り替えて確認できます。

- 案件の現在地：要件確定数、未決事項、期限、次回合意
- 要件とスコープ：今回つくるもの、対象外、見積前提
- 変更依頼：追加費用、納期、影響機能、作業内訳

### BARBER FLOW

理美容室の予約・顧客・施術履歴を一元管理する自主開発プロトタイプです。受託実績ではなく、業務をシステムへ落とし込む設計・開発例として掲載しています。

## 技術構成

- HTML
- CSS
- Vanilla JavaScript
- 外部ライブラリ、API、ビルド処理なし

静的ファイルだけで構成しているため、`index.html`をブラウザで開けば確認できます。

## ファイル構成

```text
azri-lp/
├── index.html       # ページ構造と掲載内容
├── style.css        # デザイン、レスポンシブ表示
├── script.js        # デモのタブ切替と変更影響の開閉
├── azri-logo.png    # 支給されたブランドロゴ
├── .nojekyll        # GitHub Pages用設定
└── README.md
```

## ローカル確認

`index.html`を直接開くか、任意の静的Webサーバーでリポジトリのルートを配信します。

例：

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 公開方法

GitHub Pagesを利用する場合は、リポジトリのSettingsからPagesを開き、`main`ブランチのルートを公開元に指定します。

独自ドメインを利用する場合は、公開先のURL確認後にDNSとHTTPSの設定を行います。ドメイン情報や認証情報はリポジトリへ保存しません。

## 公開前チェック

- PC・スマートフォンで文章とデモ画面が崩れていない
- キーボードで実務デモのタブを切り替えられる
- ロゴ画像、CSS、JavaScriptの参照先が正常
- 画面内の企業名・人物名・数値が架空データである
- 問い合わせ先、会社情報、プライバシー表記を確定している
- 「自主開発デモ」と「受託実績」を誤認させる表現がない

## データと免責

実務デモの企業名、人物名、日付、費用、進捗はすべて架空です。ブラウザ上で表示を切り替えるためのデモであり、入力内容の保存や外部送信は行いません。
