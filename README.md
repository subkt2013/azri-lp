# AZRI Landing Page

AZRIの業務システム開発・要件定義・保守運用の考え方を伝える、静的なコーポレートLPです。

「焦らず決めて、速くつくる。」を中心メッセージに、機能の多さではなく、業務理解・デモによる認識合わせ・変更管理まで含めた開発の進め方を表現しています。

## このサイトで伝えること

- 作り始める前に、現場の業務と例外を整理する
- 文章だけで決めず、操作できる画面で認識をそろえる
- 対象範囲、対象外、見積前提を明確にして手戻りを減らす
- 追加要望は費用・納期・影響範囲を確認してから着手する
- 納品後のバックアップ・監視・改善まで見据える

## 操作できるデモ一覧

LPのカードからデモを開き、その場で操作できます。

| デモ | 試せる操作 |
| --- | --- |
| 予約・顧客管理（BARBER FLOW） | 予約登録、日時・担当者の重複チェック、来店受付 |
| 経費申請・承認 | 承認、理由必須の差戻し、判断履歴の表示 |
| 見積作成 | 数量・単価の変更、税額・合計の自動計算、見積プレビュー |

いずれもLP用のブラウザ内体験デモです。サーバーや実際のBARBER FLOWのDBには接続せず、再度開くと初期状態になります。予約枠はカット60分に限定しています。顧客カルテの編集、通知送信、見積PDF出力はこの体験デモには含みません。

### BARBER FLOW

理美容室の予約受付・予約カレンダー・顧客カルテを一元管理する自主開発プロトタイプです。

サイトでは機能名を並べるのではなく、次の業務の流れが分かる構成にしています。

1. お客様のWeb予約と、スタッフが受けた電話・店頭予約を同じ場所へ登録する
2. 店舗の予約カレンダーへ反映し、担当スタッフの重複予約を防ぐ
3. 来店後の施術内容と注意事項を顧客カルテへ残す

受託実績ではなく、業務をシステムへ落とし込む設計・開発例として掲載しています。

## 技術構成

- HTML
- CSS
- Vanilla JavaScript
- 外部ライブラリ、API、ビルド処理なし

静的ファイルだけで構成しているため、`index.html`をブラウザで開けば確認できます。

## ファイル構成

```text
azri-lp/
├── index.html       # ページ構造と掲載内容
├── style.css        # デザイン、レスポンシブ表示
├── script.js        # デモの操作・入力検証・コピーライト年
├── azri-logo.png    # 支給されたブランドロゴ
├── .nojekyll        # GitHub Pages用設定
└── README.md
```

## ローカル確認

`index.html`を直接開くか、任意の静的Webサーバーでリポジトリのルートを配信します。

例：

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 公開方法

GitHub Pagesを利用する場合は、リポジトリのSettingsからPagesを開き、`main`ブランチのルートを公開元に指定します。

独自ドメインを利用する場合は、公開先のURL確認後にDNSとHTTPSの設定を行います。ドメイン情報や認証情報はリポジトリへ保存しません。

## 公開前チェック

- PC・スマートフォンで文章とデモ画面が崩れていない
- ロゴ画像、CSS、JavaScriptの参照先が正常
- 画面内の企業名・人物名・数値が架空データである
- 問い合わせ先、会社情報、プライバシー表記を確定している
- 「自主開発デモ」と「受託実績」を誤認させる表現がない

## データと免責

制作例の人物名、件数、金額はすべて架空です。デモでは入力内容を一時的に画面へ反映しますが、永続保存・外部送信は行いません。実在する個人情報を入力する必要はありません。
