# AZRI ポートフォリオサイト

HTML・CSS・JavaScriptのみで動作するサイトです。ビルドやAPIキーは不要です。

## プレビュー
ZIPを展開して index.html をブラウザで開いてください。

## GitHub Pagesで公開する
1. 公開先のリポジトリを作成、または既存の公開先を開きます。
2. このZIP内の index.html / style.css / script.js / .nojekyll をリポジトリのルートに配置し、main ブランチにコミットします。ZIP自体をアップロードするのではなく、展開したファイルを配置してください。
3. Settings → Pages → Build and deployment → Source で「Deploy from a branch」を選択します。
4. ブランチ「main」、フォルダ「/(root)」を選択し Save を押します。
5. Actionsの公開処理が成功したことを確認し、Pagesに表示されるURLを開きます。

公式手順（2026-09-05確認）:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 公開前に決めること
- 制作例は画面デモとして明記しています。受託実績ではありません。
- 正式な問い合わせ先が未確認のため、メールアドレス・問い合わせフォームは掲載していません。
- 所在地・法人格・顧客名・受託件数など、未確認の情報は掲載していません。
- azri-inc.com のDNS変更や独自ドメイン接続は実施していません。
